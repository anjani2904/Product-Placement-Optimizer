# Product Placement Optimizer using Market Basket Analysis

## Overview
This project uses the Apriori algorithm to identify products that are frequently purchased together. The generated association rules help recommend product placements in retail stores.

## Features
- Market Basket Analysis
- Apriori Algorithm
- Association Rule Mining
- Product Placement Suggestions
- Data Visualization using Matplotlib

## Technologies Used
- Python
- Pandas
- mlxtend
- Matplotlib

## How to Run

Install the required libraries:

```bash
pip install pandas mlxtend matplotlib
```

Run the project:

```bash
python main.py
```

## Output
The program:
- Finds frequent itemsets
- Generates association rules
- Recommends product placements
- Displays a support graph
